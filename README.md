# 🩺 پرستاریار — یادگیری پرستاری به سبک دولینگو

اپلیکیشن وب کامل و فارسی برای آموزش پرستاری با تجربه کاربری دولینگو: مسیر یادگیری با گره‌های متصل، سؤالات تعاملی (چهارگزینه‌ای، جای خالی، جفت‌سازی، فلش‌کارت، سناریوی بالینی، تصویری و درست/نادرست)، سیستم XP و استریک، لیگ‌های رقابتی، نشان‌ها، مرور هوشمند (SRS)، چالش‌های روزانه، فروشگاه قدرت‌افزا، دوستان و پیام تشویقی، حالت تاریک، PWA و پنل مدیریت محتوا.

## 🧰 پشته فناوری

- **Next.js 16 (App Router) + React 19 + TypeScript**
- **PostgreSQL** (لوکال یا Neon) با **Drizzle ORM**
- **Tailwind CSS 4** + **Framer Motion** + **canvas-confetti**
- **Zustand** (وضعیت درس) • **Zod** (اعتبارسنجی) • **Recharts** (نمودار)
- احراز هویت ایمیل/رمز عبور با کوکی HttpOnly و جدول نشست (scrypt)
- **jalaali-js** برای تاریخ شمسی

> نکته: به دلیل قالب پروژه، لایه داده با **Drizzle** پیاده‌سازی شده است (معادل Prisma). احراز هویت به صورت مستقل و سبک انجام شده و ساختار آن برای افزودن NextAuth/ورود گوگل آماده است.

## 🚀 راه‌اندازی محلی

```bash
# ۱) نصب وابستگی‌ها
npm install

# ۲) تنظیم متغیرهای محیطی
cp .env.example .env
# مقدار DATABASE_URL را ویرایش کنید

# ۳) ساخت جداول
npx drizzle-kit push

# ۴) وارد کردن داده نمونه (اختیاری — در اولین درخواست به‌صورت خودکار هم انجام می‌شود)
npx tsx src/db/seed-cli.ts

# ۵) اجرا
npm run dev
```

سپس به `http://localhost:3000` بروید.

## ☁️ استقرار روی Vercel + Neon

1. در [Neon](https://neon.tech) یک پروژه بسازید و رشته اتصال **pooled** را کپی کنید (`...?sslmode=require`).
2. مخزن را به Vercel وصل کنید و در **Environment Variables** مقدار `DATABASE_URL` را قرار دهید.
3. جداول را بسازید:
   ```bash
   DATABASE_URL="postgresql://..." npx drizzle-kit push
   ```
   (یا فایل `drizzle.config.json` را به خواندن از env تغییر دهید.)
4. Deploy کنید. در اولین درخواست، داده‌های نمونه به‌صورت خودکار وارد می‌شوند (`ensureSeeded`).
5. برای دامنه سفارشی، HTTPS فعال است و PWA قابل نصب خواهد بود.

## 📥 فرمت CSV برای ورود گروهی سؤال

ستون‌ها:

```
stationId,type,prompt,options,correctIndex,answers,pairs,back,scenario,image,explanation,difficulty,tags
```

- `type`: `multiple_choice | true_false | fill_blank | drag_drop | flashcard | scenario | image`
- `options` و `answers` با `|` جدا می‌شوند؛ `pairs` به شکل `چپ=راست|چپ=راست`
- `correctIndex` از صفر شروع می‌شود (برای درست/نادرست: ۰ = درست، ۱ = نادرست)
- شناسه ایستگاه‌ها را در تب «نمای کلی» پنل مدیریت ببینید.

## 🧠 الگوریتم مرور هوشمند

هر پاسخ، آیتم `review_items` را با نسخه‌ای از SM-2 به‌روزرسانی می‌کند:
- پاسخ اشتباه → بازه ≈ ۱۰ دقیقه، افزایش `lapses`، کاهش ضریب سهولت
- پاسخ درست → بازه ۱ روز، ۳ روز، سپس ضرب در ضریب سهولت (پاسخ سریع‌تر = کیفیت بالاتر)
- «مرور هوشمند» ابتدا آیتم‌های سررسیدشده با بیشترین خطا را می‌آورد.

## 🔐 نکات امنیتی و تولید

- رمزها با `scrypt` و salt تصادفی هش می‌شوند؛ نشست‌ها در کوکی HttpOnly/SameSite=Lax.
- لینک بازیابی رمز در نسخه نمایشی روی صفحه نمایش داده می‌شود؛ برای تولید، ارسال ایمیل (Resend/SMTP) را در `forgotPasswordAction` اضافه کنید.
- برای ورود گوگل، NextAuth را نصب و با جدول `users` یکپارچه کنید.
